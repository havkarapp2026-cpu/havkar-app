# havkar-app

HAVKAR is a multilingual multi-service web app. Production:

https://havkar-app.vercel.app

The wallet page can prepare a Stellar payment and submit it only after an external wallet signs it. Event tickets have an optional Testnet XLM checkout in the repository. It is not active on Mainnet, and its database migration has not been applied. Delivery, market, and jobs do not settle in XLM today.
