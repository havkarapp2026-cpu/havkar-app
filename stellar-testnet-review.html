Still required before a live Preview checkout

  • HAVKAR_STELLAR_TESTNET_DESTINATION: a Testnet account the owner controls. Public key only. It must already exist on Testnet. Do not send the secret key.
  • Written approval to add kraken-xlmeur to the empty provider allowlist, then HAVKAR_XLM_RATE_PROVIDER=kraken-xlmeur. The rate is read live from Kraken’s public XLMEUR ticker. No rate is stored in the repository.
  • HAVKAR_STAGING_SUPABASE_URL must be the existing staging project URL, and HAVKAR_STAGING_SERVICE_ROLE_KEY must be that project’s service-role key, set only in the Preview environment for this branch.
